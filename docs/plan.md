# 計画書：こうきくんプレゼンツ ビンゴ大会！

## 1. プロダクト概要

| 項目 | 内容 |
|---|---|
| プロダクト名 | こうきくんプレゼンツ　ビンゴ大会！ |
| 種別 | Web アプリケーション（ビンゴの番号を表示するツール） |
| 目的 | ビンゴ大会の進行役が、抽選番号をルーレット演出つきで公平に表示する |
| 基本の流れ | 番号の範囲を決める → ルーレットを回して止める → 出た番号を表示して記録する |

## 2. 画面構成と画面遷移

```
[トップ画面] ──（ゲーム開始／続きから）──▶ [ゲーム画面]
      ▲                                       │
      └────────────（トップへ戻る）───────────┘
```

## 3. 機能要件

### 3.1 トップ画面

| ID | 機能 | 詳細 |
|---|---|---|
| T-1 | タイトル表示 | 「こうきくんプレゼンツ　ビンゴ大会！」を表示する |
| T-2 | 数字の範囲設定 | 数字を入れるテキストボックスを2つ（最小値・最大値）置く。例：「1〜75」 |
| T-3 | 入力チェック | 1〜99 の整数だけを受け付ける。最小値が最大値より大きいときや空欄のときはエラーを出し、ゲームを開始させない |
| T-4 | 新しく始める | 設定した範囲で、履歴のない状態からゲームを始める。途中のゲームが残っている場合は、履歴を消してよいか確認する |
| T-5 | 続きから再開 | 途中のゲームが保存されている場合だけボタンを表示し、前回の範囲と履歴のまま再開する |

### 3.2 ゲーム画面

| ID | 機能 | 詳細 |
|---|---|---|
| G-1 | ルーレット表示 | 番号が次々に切り替わる演出を表示する |
| G-2 | 操作ボタン | 1つのボタンで「スタート」と「ストップ」を切り替える |
| G-3 | 停止の演出 | 「ストップ」を押すと1〜2秒かけて減速し、番号が1つ決まる。止まりきるまでボタンは押せない |
| G-4 | 均等な抽選 | まだ出ていない番号の中から、どれも同じ確率で選ぶ |
| G-5 | 重複なし | 一度出た番号は二度と出さない |
| G-6 | 履歴の常時表示 | 出た番号を、出た順に画面内に並べていく |
| G-7 | 効果音 | 回転中はドラムロール、決定時は決定音を鳴らす。画面上のボタンでオン・オフを切り替えられる |
| G-8 | 残り数の表示 | 「残り ○ 個」と表示する |
| G-9 | 出尽くし時の扱い | すべての番号が出たらボタンを押せなくし、終了を知らせる |
| G-10 | トップへ戻る | トップ画面に戻る。履歴は消さずに残す |

### 3.3 データの保持

- 範囲・履歴・効果音のオン/オフはブラウザ（localStorage）に保存する。ページを再読み込みしても、ブラウザを閉じても続きから再開できる
- 一度出た番号は取り消せない仕様とする

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| 対応デバイス | PC につないだ大画面（プロジェクター・大型モニター）と、スマホ・タブレットの両方。画面サイズに合わせてレイアウトを調整する |
| 動作環境 | 最新の Chrome / Safari / Edge（PC版・スマホ版） |
| 構成 | HTML / CSS / JavaScript だけで作る。サーバーもビルドも不要 |
| 公開方法 | Web 上で公開する（GitHub Pages などの静的ホスティングを想定） |
| 公平性 | 乱数は `crypto.getRandomValues` を使い、偏りの出ない方法で選ぶ |
| 視認性 | 会場の遠くからも読めるよう、番号は大きな文字で表示する |
| デザイン | 明るい色と大きな文字を使った、ポップでにぎやかな雰囲気 |
| 効果音 | 音声ファイルを使わず Web Audio API で合成する（素材の権利の心配がない） |

## 5. 補足（前提として置いた点）

- 最小値は 1 からとする。0 から始めたい場合は変更する。
- 「直前の番号を大きく見せる」機能は設けない。ルーレットは止まった番号を表示したままなので、次に回すまではその番号が大きく見えている。
- 公開先は未確定。GitHub Pages を第一候補とする。
